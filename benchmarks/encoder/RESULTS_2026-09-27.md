# MiniCPM-o 4.5 encoder input selection: 2026-09-27

Screening run on one RTX 5090 host, using the existing `0z5a` environment (vLLM 0.29.0, PyTorch 2.13.0+cu130). The input contained two images with two slices each. Five alternating trials timed 1,000 `get_encoder_cudagraph_item_specs` plus `select_encoder_cudagraph_items` pairs per arm; the table reports the median per pair. The uncached arm removed the parsed-input cache entry between the two calls to reproduce the previous repeated parsing behavior.

| Path | Median per pair (ms) | Speed vs. repeated parse | Time reduction |
| --- | ---: | ---: | ---: |
| Repeated vision-input parse | 0.157986 | 1.00× | — |
| Reused parsed input | 0.110143 | 1.43× | 30.3% |

CPU tests: 20 passed, 7 skipped. The skipped cases require vLLM's `capture_axes` encoder Graph protocol, which this installed vLLM does not expose. The speedup above measures CPU input selection, not encoder Graph replay.

## Full-checkpoint image/video to text E2E on GPU 6

Ran the unmodified MiniCPM-o 4.5 checkpoint (`503e754207c94da6bb26850b4469f367c9ea3582`) on one RTX 5090 in the existing `0z5a` environment. All four checkpoint shards were verified against their source SHA-256 values before loading. The test registered the model's existing Thinker topology as a single-stage pipeline because the installed environment lacks the `s3tokenizer` dependency required by the audio stage. The source changes in this PR were active for both requests.

| Request | First request (s) | Repeated request (s) | Repeated token IDs |
| --- | ---: | ---: | --- |
| 224×224 red-circle image → text | 18.307 | 0.202 | Identical |
| Two-frame red-circle video → text | 17.376 | 0.690 | Identical |

The first request includes one-time model and kernel warmup. These timings do not compare this PR against the earlier implementation. The installed vLLM 0.29.0 `EncoderCudaGraphConfig` lacks `capture_axes`, so this run exercised the documented eager fallback; it cannot establish encoder Graph capture, token parity against Graph replay, or an E2E Graph speedup. The full three-stage audio pipeline also cannot start without `s3tokenizer`. The model weights were removed after this run.
