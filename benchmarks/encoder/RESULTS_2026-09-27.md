# BAGEL encoder item selection: 2026-09-27

Screening run on RTX 5090 GPU 1 in the existing `0z5a` environment (vLLM 0.29.0, PyTorch 2.13.0+cu130). BF16 tensors held three images. Five alternating trials timed 300 selections per arm; the table reports the median per selection. The comparison is advanced indexing from the previous code against a contiguous `narrow` view.

| Input image size | Advanced indexing (ms) | Contiguous view (ms) | Selection speedup |
| --- | ---: | ---: | ---: |
| 512 × 512 | 0.028810 | 0.003909 | 7.37× |
| 1024 × 1024 | 0.028594 | 0.004006 | 7.14× |

CPU tests: 20 passed. GPU encoder-manager replay tests: 4 passed. The Graph manager copies selected pixels into its replay buffer, so the speedup above applies only to selection; it is not an end-to-end encoder or serving result. Full-model comparison and the batch-2 output-difference investigation remain pending.
