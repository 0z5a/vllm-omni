# YuE2 CUDA Graph E2E: 2026-09-27

Real `m-a-p/YuE2-3B` weights (revision `14fc6c6f146441b1dd6363fcb2e01e82a6914cb7`, safetensors SHA256 `1d55c42c1a9875c34f5d736e15078449992b044e807ce2a138e6cf289a1e59e9`) and `m-a-p/YuE2-Vae` (revision `9a94e1d0ea9f8087e98f77fa88df4a4068104d2a`) ran from local EXT4 on one RTX 5090. The existing `0z5a` environment had vLLM 0.29.0 and PyTorch 2.13.0+cu130. No package versions were changed. Model files were removed after validation.

`bench_e2e.py` keeps one engine alive per arm, runs one warmup, then times `engine.generate` including AR, NAR, and VAE. All arms used the same checkpoint, seed 831001, prompt, BF16, and 0.5 GPU memory utilization. Repeated arms ran sequentially on GPU 6. The table uses medians of timed requests; the two-request `cot=full` row is one fresh-process run per arm on GPU 7. Engine initialization and WAV file writing are outside the timed interval.

The 25-frame sampled runs generated the same token hash in all six requests per arm. The 200-frame compiled/no-Graph and PIECEWISE runs generated the same token hash `6e2f50d21fc1…` and audio hash `b6c0b73b28c4…` in every request. The full two-phase WAV SHA256 was `2b60a6385a9260ead4d4b1b515e7c5f67f77a46fc0e27fffdb503864fb468448` on both arms. The 200-frame eager/compiled difference starts at token index 11, so its 1.53× row does not establish output-equivalent performance. Eager and compiled also diverged in `cot=full` at ABC token index 117; PIECEWISE matched compiled/no-Graph exactly. FULL decode Graph introduced an additional 200-frame difference from compiled/no-Graph at token index 117, so the deploy configuration selects `PIECEWISE`.

AR timing comes from `YUE2_TIMING` and excludes terminal NAR/VAE. A temporary runner log confirmed one 39-token prefill dispatched as `NONE`, followed by 25 one-token decode steps dispatched as `PIECEWISE`. It was removed after the probe. Capture reported 0.05 GiB of Graph memory. Real-weight offline `cot=off` and `cot=full` requests saved finite 48 kHz stereo WAVs; the frame cap marked them as truncated. Six sequential requests in one engine completed with identical outputs within each arm. After checkpoint cleanup, 94 focused row-state, model-contract, and runner tests passed.

Reproduce the repeated measurement with `HF_HUB_OFFLINE=1`, `YUE2_VAE` set to the local VAE directory, and `PYTHONPATH` set to this checkout:

```bash
python benchmarks/yue2/bench_e2e.py --model /path/to/YuE2-3B \
  --deploy-config /path/to/yue2-piecewise.yaml --max-frames 25 --requests 5
python benchmarks/yue2/bench_e2e.py --model /path/to/YuE2-3B \
  --deploy-config /path/to/yue2-piecewise.yaml --max-frames 200 --requests 3 --greedy
```

The deploy YAML in this change is the PIECEWISE arm; the recorded run pointed its placeholder tokenizer path at the local checkpoint. For the baselines, use the same YAML with `enforce_eager: true`, or with `enforce_eager: false` and `compilation_config.cudagraph_mode: NONE`, respectively. Audio quality was checked for finite samples and paired hashes/correlation, not scored perceptually. This PR remains Draft pending a broader quality gate and concurrent real-request run.
